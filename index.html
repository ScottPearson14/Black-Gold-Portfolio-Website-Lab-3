Projects & Achievements

Who Wants to Be a Millionaire Trivia Game

This project is a collaborative team hackathon project that took place over the span of 48 hours. We developed a feature-rich, multi-user trivia game in a networked environment all within the allowed timeframe. We designed a visually engaging Java Swing GUI and a multithreaded server to support multiple client connections. We also integrated an SQL database for dynamic question retrieval and user account management.

Geo Facility Location Optimization Project

Geo Facility Location Optimization Project: This project explores solutions to the p-median facility location problem using real-world U.S. city data and distance calculations. Through multiple algorithmic phases, the goal is to determine optimal facility placements that minimize total distance to demand points. Visualization outputs are rendered in Google Earth-compatible KML format. The project processes a dataset of U.S. cities and their intercity distances to calculate optimal facility locations for varying values of p (e.g., p=1, p=3, p=5, p=8). It includes phases for brute-force optimization, heuristic algorithms, and geographical visualization.
