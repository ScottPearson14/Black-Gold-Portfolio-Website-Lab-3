Projects & Achievements

Who Wants to Be a Millionaire Trivia Game

This project is a collaborative team hackathon project that took place over the span of 48 hours. We developed a feature-rich, multi-user trivia game in a networked environment all within the allowed timeframe. We designed a visually engaging Java Swing-based GUI and developed a multithreaded server to support multiple client connections. We also integrated an SQL database for dynamic question retrieval and user account management.

Geo Facility Location Optimization Project

Geo Facility Location Optimization Project: This project explores solutions to the facility location problem using real-world U.S. city data and distance calculations. I wrote Python scripts to calculate great-circle distances using the Haversine formula, built a complete weighted graph with geodesic edge weights, and implemented custom algorithms to efficiently find optimal facility locations under different constraints.
